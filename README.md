# Katalog

Pick archetypes from a catalog. Name, license, targets, and flags in. Our standards and libraries out.

**Package:** `@kolektiv/katalog` · **CLI:** `katalog new`

Katalog is the Kolektiv project scaffold: mix-and-match archetypes (KMP app/lib, Ktor+Keel host, JS/Vite+, Cloudflare Worker, Astro docs/site, hybrid), wire preferred libraries, and emit repo hygiene (labels, templates, LICENSE, docs) from inputs.

See [KolektivComputer/.github](https://github.com/KolektivComputer/.github) for org conventions. Companion runner: [Kascade](https://github.com/KolektivComputer/kascade).
